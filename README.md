# How?

仮想環境は不要。とりあえず各フォルダの ``main.py`` を実行すると何をしたいかは伝わるはず。

生徒が実装することを想定した ``my_ai.py`` は初期状態（＝ランダム・最弱）なので、とりあえず実行してトントン、もしくは先行/後攻有利に依存した結果になることを確認。

コメントアウトにて想定しているアレンジ例を掲載しているので、それに切り替えて再度実行してもらえれば、頑張れば強いBotが作れるようになることが伝わると思います。

# オリジナルゲームのルール

### 基本ルール
このゲームは2人対戦のカードゲームで、7ターンで勝敗が決まります。

**初期設定：**
- 各プレイヤーは1～13の数字カード（13枚）を手札として持ちます
- スコア用の山札には、ハート（+1～+13）とダイヤ（-1～-13）の計26枚がシャッフルされて用意されます

**ゲームの流れ（全7ターン）：**
1. 山札から2枚めくり、その**掛け算**がそのターンの得点になります
   - 例：+5と+8なら +40点、-3と+7なら -21点、-4と-6なら +24点
2. 両プレイヤーは同時に手札から1枚を選んで出します（使ったカードは戻りません）
3. **数字が大きい方がそのターンの得点を獲得**します
   - 引き分けの場合、得点は流れます（どちらも獲得できません）
4. 7ターン終了後、合計スコアが高い方が勝利です

### ゲーム性の特徴

**心理戦の要素：**
- プラスの得点なら勝ちたいが、マイナスの得点なら負けたい（相手に押し付けたい）
- 手札は13枚しかなく、使い切りなので、どのタイミングで強いカードを使うかが重要
- 相手の使用済みカードから、残りの手札を推測できる

**運と戦略のバランス：**
- 山札の引きによって得点が変動するため運要素がある
- しかし、限られた手札をどう配分するかという戦略性も高い

## 実装されている戦略（my_ai.py）

**1. 得点の大きさに応じた出し分け：**
- 超高得点（100点以上）：最強カード（13）を惜しみなく投入
- 中程度の得点（30～99点）：中間カード（7前後）で節約
- 低得点（1～29点）：弱めのカード（2など）で様子見

**2. マイナス得点の回避：**
- 大ダメージ（-50点以下）：最弱カード（1）を出してわざと負ける
- 軽いマイナス：最弱カードで負けを狙う

## 想定される追加戦略

**1. 相手の手札推測戦略：**
- 相手の使用済みカード（enemy_used）から残り手札を逆算
- 例：相手が13を使っていれば、次のターンで12以下しか出せないと分かる
- 高得点ターンで「相手の最大値+1」のカードを出せば確実に勝てる

**2. スコア差に応じた戦略：**
- 大きくリードしている時：リスクを避け、中程度のカードで安定プレイ
- 大きく負けている時：マイナスを積極的に引き取り、プラスで一発逆転を狙う
- 接戦の時：相手の残り手札を読んで、ギリギリ勝てるカードを選ぶ

**3. ターン進行を考慮した戦略：**
- 序盤（1～3ターン）：様子見で中程度のカードを使う
- 中盤（4～5ターン）：相手の傾向を読んで調整
- 終盤（6～7ターン）：残り手札が限られるため、確実性の高い選択をする

**4. 期待値計算戦略：**
- 山札の残りから次のターンの得点期待値を計算
- 例：山札に大きなプラスが多く残っていれば、強いカードを温存する
- ただし、現在の実装では山札情報は渡されないため、確率的推測が必要

**5. 引き分け狙い戦略：**
- 相手の残り手札を読んで、同じ数字を出して引き分けに持ち込む
- マイナス得点を相手に取らせたい時や、プラス得点を相手に渡したくない時に有効

**6. ブラフ戦略：**
- 序盤にあえて強いカードを使って相手を威圧
- 相手に「この人は高得点で強いカードを使う」と思わせ、中盤以降の読み合いを有利にする
